The development record covers the work created during ETHOnline 2026, including Plans 1–8 and Plans 9–12.

1. Use [setup and operation guides](guides/README.md) for local development, Rescue onboarding and the separate operator workflow.
2. Open the unified [Plan 1–12 index](plans/README.md) to follow the implementation sequence.

4. Use [STATUS](../STATUS.md) for the current implementation boundary, rather than treating every dated plan as a current backlog.

Internal coordination and owner-operation notes are local-only; the development plans and implementation records remain public.
