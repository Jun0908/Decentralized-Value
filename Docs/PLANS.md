## Reading evidence

- **Implemented** means the code exists within the stated scope.
- **Locally verified** and **publicly verified** identify different environments.
- **Simulation** describes the game or workflow execution boundary, not whether a separate model call or test-chain payment occurred.
- **Committed**, **funded**, and **paid** require their own evidence.
- **Next milestone** is not available functionality.

No single weighted score resolves the independent outcome axes. No presentation change upgrades a fixture into a real AI run, a simulation into live TEE execution, or a pool preview into a payment.
