# Verify what actually happened

1. Read [STATUS](../STATUS.md) for the current concise boundary.
2. Open a [dated verification report](verification/README.md) for its environment, checks, failures and exclusions.
3. Inspect the corresponding [machine-readable record](deployments/) for transaction, execution or replay evidence.

Use the [sponsor evidence map](../hackathon/sponsors/README.md) to connect sponsor claims to implementation and JSON. These records include offchain runs and draft configuration, not only deployments; the `deployments/` name is retained for recognizable evidence filenames.

Raw records are historical evidence. Do not rewrite their outcomes, timestamps or provenance when reorganizing documentation. A recorded path may refer to the old repository layout. Current source readers and generators use `Docs/evidence/deployments/`; archived originals preserve their original bytes.

Simulation, commitment and payment are different states. Neither a build nor a saved record establishes that a new public AI run completes.
