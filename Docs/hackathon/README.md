# Prepare the submission and demonstration

1. Read [submission scope](submission/HACKATHON_SUBMISSION.md) against [current status](../STATUS.md).
2. Use [submission materials](submission/README.md) for English copy and handoff.
3. Use [sponsor guides](sponsors/README.md) for ENS, Chainlink CRE and Bazantic source links and evidence boundaries.
4. Use the [public demo walkthrough](DEMO.md) to inspect the product. [Illustration provenance](../product/arenas/ILLUSTRATIONS.md) documents the development assets.

Video scripts, narration, take logs, editing notes and footage are local-only and Git-ignored. Public source code, plans, demo instructions and execution evidence remain in the repository.

The demonstration explains existing evidence. Opening a page, reading a script or moving these documents does not run an AI, make a payment, deploy a workflow or confirm eligibility. Actual records remain in [evidence](../evidence/README.md), not duplicated here.
