# Understand the product

1. Read [PRODUCT](../PRODUCT.md) for independent values, correctness and comparison rules.
2. Read the relevant [Arena specification](arenas/) for domain-specific rules.
3. Read [ARCHITECTURE](../ARCHITECTURE.md) for execution and trust boundaries.
4. Use the [whitepaper reference](whitepaper/README.md) for the ideas and research background.

For what actually works today, use [STATUS](../STATUS.md). For unfinished implementation, use [development plans](../development/plans/README.md); a design is not proof that a feature is deployed.

Arena documents cover [Disaster Response](arenas/disaster-response.md), [Emergency Supply](arenas/emergency-supply.md), [Calldata](arenas/calldata-compression.md), [Rescue](arenas/rescue-room.md) and [Secret Gate](arenas/secret-gate.md). Ocean and Microgrid currently retain their detailed design in [Plan 10](../development/plans/Plan10.md) and [Plan Microgrid](../development/plans/Plan-Microgrid.md); this move does not invent missing standalone specifications.
